# AgenticRAG

This repository contains a survey of architectures for answering multi-step and
complex queries, with an emphasis on retrieval-augmented generation (RAG),
agentic control, optimization, evaluation, and cost–quality trade-offs.

## Survey

- [A Survey of Multi-Step and Complex Query Answering](SURVEY_PAPER.md)

## Scope

The paper is intended as an architecture-level and evidence-oriented survey.
It covers:

- naive, modular, iterative, corrective, graph-based, and agentic RAG;
- query decomposition, interleaved reasoning and retrieval, tool use, memory,
  reflection, and multi-agent coordination;
- retrieval, generation, orchestration, and serving optimizations;
- evaluation datasets and metrics;
- cost, latency, quality, and reliability trade-offs; and
- open research problems for production systems.
